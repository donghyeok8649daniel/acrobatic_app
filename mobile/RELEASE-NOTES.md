# Acrobatic Mobile 0.3.3

**갤럭시·안드로이드 설치:** `Acrobatic-Android-0.3.3.apk`를 다운로드하고 파일을 열어 설치한다. 다운로드한 브라우저/파일 앱의 ‘이 출처 허용’ 요청이 나오면 설치를 허용한다. 앱 안에서 각자의 KAIST 이메일로 로그인한다.

앱은 기존 팀 서버에 연결한다. 훈련 가이드·모식도는 오프라인에서 볼 수 있고, 앱 설정에서 매주 월요일 18:15 개인 알림을 켤 수 있다. 새 공지의 원격 푸시는 아직 연결되지 않았다.

**아이폰 무료 설치:** `Acrobatic-iOS-resign-0.3.3.ipa`를 Sideloadly 또는 SideStore에서 본인의 무료 Apple ID로 재서명해 설치한다. 서명은 7일마다 갱신해야 한다. 처음에는 컴퓨터 연결과 기기 신뢰·개발자 모드 설정이 필요하다. 함께 제공하는 `iPhone-install.md`와 저장소의 `mobile/SIDELOAD.md`를 참고한다. IPA를 눌러 직접 설치하는 방식은 아니며, 실제 Apple ID 서명·실기기 설치는 사용자가 진행한다.

훈련 가이드의 A/B킥 모식도를 수정했다. 수비 코트의 수비수 둘 다 같은 코트 세터보다 네트에서 먼 후방에 위치한다.
Android API 35 에뮬레이터와 iPhone 시뮬레이터 검사, iOS 기기용 컴파일을 릴리스 전에 실행한다. `SHA256SUMS.txt`에 APK의 해시가 포함된다. APK 서명 키와 개인 팀 기록은 공개 소스에 포함하지 않는다.
