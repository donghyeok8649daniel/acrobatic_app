# KAIST Acrobatic

KAIST 족구동아리 아크로바틱의 전용 운영 앱이다. 한국어와 영어를 지원하며, Cloudflare Workers와 D1을 공통 서버로 사용한다. 갤럭시·아이폰에서는 홈 화면에 설치하는 웹 앱으로, Windows에서는 같은 서버에 연결하는 데스크톱 앱으로 사용할 수 있다.

## 주요 기능

- KAIST 이메일 로그인, 학번 기반 초기 비밀번호, 첫 로그인 비밀번호 변경
- 가입 신청과 동장 승인, 직책 지정과 동장 인수인계
- 프로필 사진, 주발 표시, 동장이 관리하는 활동 여부
- 훈련 매뉴얼과 모식도, 매뉴얼을 선택하는 훈련공지, 참석 투표
- 주간 다이어리와 훈련시간표
- 동비 장부, 학기별 개인 회비 납부, 통장 정보와 담당자 인계
- 구글 시트와 양방향 동기화, 같은 항목의 충돌 감지
- 휴대폰 푸시 알림, 새 빌드 감지와 업데이트 버튼

계좌 정보와 담당자를 보관하며, 입출금은 동비 장부나 연결된 시트에서 기록한다. 회비 납부 현황은 장부 수입에 중복 합산하지 않는다.

## 개발과 검증

Node.js 24를 사용한다.

```sh
npm run install:ci
npm run typecheck
npm run test:unit
npm run build
npm run test:integration
npm run test:email-sheets
```

통합 검사는 운영 데이터와 분리된 로컬 D1에서 실행한다. 푸시 전송은 테스트용 송신기로 대체하므로 실제 사람에게 테스트 메시지를 발송하지 않는다.

## 배포 설정

`DEPLOY-CLOUDFLARE.md`에 따라 개인 Cloudflare 배포 설정을 준비한다. 계정·DB 설정과 실제 명단은 저장소에 넣지 않는다. 필요한 서버 비밀 값은 다음과 같다.

- `AUTH_PEPPER`: 비밀번호 해시용 서버 비밀 값
- `SHEET_SYNC_CONFIG`: 연결할 팀과 스프레드시트의 ID
- `SHEET_SYNC_TOKEN`: 시트 연동 전용 비밀 키
- `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`: 웹푸시 서명 키

```sh
npm run deploy:cloudflare
```

새 빌드에는 자동으로 고유한 빌드 시각을 넣는다. 화면은 새 빌드를 확인하면 업데이트 버튼을 표시한다. 기존 기록은 D1에 저장되므로 화면 업데이트 후에도 유지된다.

## 구글 시트 연결

동장 계정으로 로그인한 뒤 **팀 설정 → Google 시트 연동**에서 설정된 스크립트를 내려받는다. 연결된 시트의 **확장 프로그램 → Apps Script**에 붙여넣고 `installAcrobaticSync`를 한 번 실행한다. Google 권한 승인 후 5분마다 연동한다.

스크립트는 원래 시트의 옆쪽 요약이나 수식을 덮어쓰지 않으며, 행 식별자를 사용해 새 기록과 기존 기록을 구분한다. 마지막 동기화 이후 같은 항목이 양쪽에서 다르게 바뀌면 덮어쓰지 않고 충돌을 알린다. 비밀번호를 다시 초기화하지 않는다. 내려받은 설정 스크립트에는 연결 키가 있으므로 공개 저장소에 올리지 않는다.

## 휴대폰 설치와 알림

- 갤럭시: Chrome에서 앱 설치 또는 홈 화면에 추가
- 아이폰: Safari에서 공유 → 홈 화면에 추가
- 알림: 설치한 앱의 팀 설정에서 직접 허용

아이폰 웹푸시는 iOS 16.4 이상에서 홈 화면에 설치한 앱을 사용한다. 새 공지·훈련공지·주간 다이어리를 게시하면 푸시 대기열에 넣으며, 일시적인 전송 실패는 서버가 재시도한다. 기기와 브라우저의 알림 권한은 사용자가 직접 허용해야 한다.

## 카카오톡과 후속 기능

일반 단톡방의 카카오 기본 투표를 생성·조회·수정하는 연동은 현재 포함하지 않는다. 조사한 오픈소스는 `storycraft/node-kakao`, `dolidolih/Iris`, `JungHoonGhae/openkakao-cli`이며, 네이티브 투표 양방향 동기화를 검증하지 못했다. Iris는 상시 안드로이드 중계기가 필요하다. 앱의 참석 투표 링크와 당일 매뉴얼은 공유할 수 있다.

영수증 첨부, 실제 훈련 출석부, 친목조 점수는 후속 버전 범위다. 현재는 참석 예정 투표와 친목조 구성만 제공한다.
