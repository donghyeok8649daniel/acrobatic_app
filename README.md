# KAIST Acrobatic

KAIST 족구동아리 아크로바틱의 전용 운영 앱이다. 한국어와 영어를 지원하며, Cloudflare Workers와 D1을 공통 서버로 사용한다. 갤럭시·Android용 서명 APK와 iOS 앱 프로젝트, Windows EXE를 제공한다. 아이폰 설치 배포는 Apple Developer 서명 연결 전이라 아직 사용할 수 없다. 브라우저에서도 같은 팀 서버를 이용할 수 있다. 모바일 빌드·검증과 배포 상태는 [mobile/README.md](mobile/README.md)에 정리했다.

## 주요 기능

- KAIST 이메일 로그인, 학번 기반 초기 비밀번호, 첫 로그인 비밀번호 변경
- 가입 신청과 동장 승인, 직책 지정과 동장 인수인계
- 프로필 사진, 주발 표시, 동장이 관리하는 활동 여부
- 훈련 매뉴얼과 모식도, 매뉴얼을 선택하는 훈련공지, 참석 투표
- 주간 다이어리와 훈련시간표
- 동비 장부, 학기별 개인 회비 납부, 통장 정보와 담당자 인계
- 구글 시트 변경 자동 반영, 앱에서 수정한 기록 보존과 충돌 감지
- 휴대폰 푸시 알림, 새 빌드 감지와 업데이트 버튼

계좌 정보와 담당자를 보관하며, 입출금은 동비 장부나 연결된 시트에서 기록한다. 회비 납부 현황은 장부 수입에 중복 합산하지 않는다.

## 개발과 검증

Node.js 24를 사용한다.

```sh
npm run install:ci
npm run typecheck
npm run test:unit
npm run build
npm run test:integration
npm run test:email-sheets
```

통합 검사는 운영 데이터와 분리된 로컬 D1에서 실행한다. 푸시 전송은 테스트용 송신기로 대체하므로 실제 사람에게 테스트 메시지를 발송하지 않는다.

## 배포 설정

`DEPLOY-CLOUDFLARE.md`에 따라 개인 Cloudflare 배포 설정을 준비한다. 계정·DB 설정과 실제 명단은 저장소에 넣지 않는다. 필요한 서버 비밀 값은 다음과 같다.

- `AUTH_PEPPER`: 비밀번호 해시용 서버 비밀 값
- `SHEET_SYNC_CONFIG`: 연결할 팀과 스프레드시트의 ID
- `SHEET_SYNC_TOKEN`: 시트 연동 전용 비밀 키
- `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`: 웹푸시 서명 키

```sh
npm run deploy:cloudflare
```

새 빌드에는 자동으로 고유한 빌드 시각을 넣는다. 화면은 새 빌드를 확인하면 업데이트 버튼을 표시한다. 기존 기록은 D1에 저장되므로 화면 업데이트 후에도 유지된다.

## 구글 시트 연결

서버가 이미 읽기 허용된 시트의 명단·지출·회비·회의록을 5분마다 읽는다. 휴대폰에서 스크립트를 설치하거나 코드를 붙여넣을 필요가 없다. 동장은 **팀 설정 → Google 시트 연동 → 지금 시트 반영**으로 즉시 갱신할 수 있다. 서버의 비공개 `SHEET_SYNC_CONFIG`에 `pullEnabled: true`와 각 탭의 gid를 설정한다. 서버는 시트 공유 권한을 변경하지 않는다.

앱에서 입력한 기록은 공동 서버에 저장된다. Google 쓰기 권한이 없는 현재 연결에서는 앱의 수정 내용을 Google 시트에 자동으로 쓰지 않는다. 마지막 반영 이후 같은 항목이 양쪽에서 다르게 바뀌면 덮어쓰지 않고 충돌을 알린다. 시트의 새 부원은 승인 대기 신청으로 등록하며 자동으로 로그인 권한을 부여하지 않는다. 숨긴 기록 ID 열은 행 이동과 삽입 시 기존 기록을 구분하는 데 사용한다. 기존 비밀번호는 다시 초기화하지 않는다.

## 휴대폰 설치와 알림

Android 설치 파일은 GitHub의 `mobile-v*` 릴리스에서 받는다. iOS 소스 ZIP은 설치 파일이 아니며 TestFlight 배포 연결이 필요하다. 다운로드 앱의 개인 반복 알림과 브라우저 웹푸시는 별개다. 네이티브 원격 푸시는 아직 연결되지 않았다. 아래는 선택 가능한 브라우저 웹 앱 설치 방법이다.

- 갤럭시: Chrome에서 앱 설치 또는 홈 화면에 추가
- 아이폰: Safari에서 공유 → 홈 화면에 추가
- 알림: 설치한 앱의 팀 설정에서 직접 허용

작은 화면에서는 하단 메뉴, 터치 버튼, 표 가로 스크롤을 사용한다. 아이폰의 홈 표시줄 여백과 입력창 확대를 고려했다. 설치한 앱과 일반 브라우저가 같은 서버에 연결하므로 기기 사이에서 별도로 데이터를 옮길 필요가 없다.

아이폰 웹푸시는 iOS 16.4 이상에서 홈 화면에 설치한 앱을 사용한다. 새 공지·훈련공지·주간 다이어리를 게시하면 푸시 대기열에 넣으며, 일시적인 전송 실패는 서버가 재시도한다. 기기와 브라우저의 알림 권한은 사용자가 직접 허용해야 한다.

## 카카오톡과 후속 기능

일반 단톡방의 카카오 기본 투표를 생성·조회·수정하는 연동은 현재 포함하지 않는다. 조사한 오픈소스는 `storycraft/node-kakao`, `dolidolih/Iris`, `JungHoonGhae/openkakao-cli`이며, 네이티브 투표 양방향 동기화를 검증하지 못했다. Iris는 상시 안드로이드 중계기가 필요하다. 앱의 참석 투표 링크와 당일 매뉴얼은 공유할 수 있다.

영수증 첨부, 실제 훈련 출석부, 친목조 점수는 후속 버전 범위다. 현재는 참석 예정 투표와 친목조 구성만 제공한다.
